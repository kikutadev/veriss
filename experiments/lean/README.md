# Lean certificate checker (research)
Goal: independent, kernel-checked soundness of affine halfspace certificates, coverage by exhaustive splits, and bounded interpolation. Existing HTML/CSS extraction and TypeScript migration remain untouched.
Acceptance: build real Lean proofs without sorry or custom axioms; check valid, missing, altered, boundary and contradictory certificates, and replay existing exported affine evidence. Distinguish mathematics of supplied model from correctness of extraction. Keep Lean optional, outside npm runtime. Use exact arithmetic and reject unsupported inputs.
