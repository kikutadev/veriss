# ADR-0018: ゲーム UI の契約と観測の分離

Status: Accepted (fork)

## 背景
ページ単位の CSS モデルが Unknown になると、無関係な HUD の契約まで検査できない。
ゲームは状態遷移、入力環境、スクロール、Canvas と DOM の座標が混在する。
スナップショットの見た目を真と仮定したり、有限個の実測から連続範囲の保証を出したりしてはいけない。

## 決定
ゲーム全体の JS を形式化せず、有限抽象状態グラフと環境プロファイルに対して
独立した GameContract / GeometryEvidence / GameObligation を照合する。
既存の CSS LayoutIR は証拠の一種。Canvas は同一 CSS px 座標系への写像をゲーム実装から
供給する。局所モデルは独立境界・写像が外部仮定であることを露出し、全ページの証明と区別する。
観測は別の結果として保持する。証明と観測を混ぜて Verified にしない。
実装仕様は [game-ui-model](../game-ui-model.md)。

## 代替
- JS 全実行状態の静的証明: 任意の JS には適用できず、検証コストも制御できない。
- Playwright の点サンプリングだけ: 実際のブラウザーには強いが連続領域・未訪問状態を保証しない。
- CSS を無視し全 UI の矩形を手で入力: 実装との乖離を隠すため採用しない。
  実装由来の明示幾何は仮定ラベルを付けた条件付き証拠として扱う。

## 影響
UI の設計仕様を CSS から独立させ、unknown の局所化と状態・環境ごとの被覆を可視化できる。
抽象グラフの完全性、ブラウザーの丸め、局所境界の妥当性、Canvas 写像の正しさは別の信頼仮定。
アクセス可能性やアニメーション途中は静的な矩形だけでは保証しない。
